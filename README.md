# orbit — 익명 커뮤니티

로그인 없이 게시글, 댓글, 대댓글을 작성할 수 있는 Next.js 풀스택 커뮤니티 과제입니다.

## 실행

프로젝트 폴더에서 npm install 후 npm run dev를 실행합니다.

DATABASE_URL이 있으면 Postgres에 테이블을 자동 생성하고, 없으면 로컬 개발 편의를 위해 data/community.json을 사용합니다. Vercel 배포에서는 DATABASE_URL을 반드시 연결해 주세요. 배포 환경의 파일 시스템은 영구 저장소가 아니므로 JSON 폴백은 로컬 데모용입니다.

DATABASE_URL 없이 배포하면 시드 데이터와 작성 기능이 메모리 폴백으로 동작합니다. 이 모드는 서버리스 인스턴스가 교체될 때 초기화될 수 있으므로, 제출용 배포에서 게시글을 영구 보존하려면 Postgres 연결을 추가해야 합니다.

## 기능

- 익명 닉네임으로 게시글 작성
- 카테고리 필터와 키워드 검색
- 게시글 목록 및 /posts/[id] 상세 보기
- 댓글 작성과 댓글별 대댓글
- Postgres 영구 저장 및 로컬 JSON 폴백

## 배포 메모

Vercel에서 프로젝트 루트를 이 폴더로 지정하고 DATABASE_URL 환경 변수를 추가하면 됩니다. GitHub에는 이 폴더만 별도 저장소로 올리면 과제의 개별 프로젝트 조건을 만족합니다.
